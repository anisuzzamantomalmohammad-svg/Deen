HOW TO BUILD THE DEEN APK
(about 15-30 minutes, mostly waiting for Expo's servers)

You need: a computer with internet, and a free Expo account.

1. Install Node.js (the "LTS" version) from https://nodejs.org
2. Create a free account at https://expo.dev/signup
3. Unzip this folder somewhere easy, e.g. your Desktop.
4. Open a terminal inside the folder:
     Windows: open the folder, click the address bar, type  cmd  and press Enter
     Mac:     right-click the folder > New Terminal at Folder
5. Run these commands one at a time:
     npm install
     npm install -g eas-cli
     eas login
     eas init
     eas build -p android --profile preview
6. When it asks:
     "Create an EAS project?" / "Link to project?" -> Yes
     (eas init writes your project ID into app.json - needed before building)
     "Generate a new Android Keystore?"      -> Yes
7. Wait for the build. When it finishes you get a link and a QR code.
   Open the link on your phone and download the APK.
8. Tap the APK to install. If Android blocks it, allow
   "Install unknown apps" for your browser or Files app when prompted.
9. First launch: allow Location and Notifications.

CHECK ON THE PHONE AFTER INSTALLING
1. Settings: the "Keep your log safe" card. Tap Sign in with Google, pick
   your account. The card turns into your name and photo.
2. Settings > Backup > Back up now. It should say "Backed up to Google Drive".
   Then Restore from Drive should list that backup.
3. Settings > Backup > Important days. Allow calendar, pick your Gmail
   calendar, Add. Open Google Calendar a minute later: Eid, Ramadan etc.
   should be there.
4. Hijri tab: new day tiles. Tap the "Hijri" pill to switch to regular dates
   and back.
5. If sign-in shows "DEVELOPER_ERROR": the SHA-1 or package name in Google
   Cloud doesn't match. Send me a screenshot.
