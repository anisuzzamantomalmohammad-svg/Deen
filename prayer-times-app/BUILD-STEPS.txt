HOW TO BUILD THE DEEN APK
(about 15-30 minutes, mostly waiting for Expo's servers)

You need: a computer with internet, and a free Expo account.

1. Install Node.js (the "LTS" version) from https://nodejs.org
2. Create a free account at https://expo.dev/signup
3. Unzip this folder somewhere easy, e.g. your Desktop.
4. Open a terminal inside the folder:
     Windows: open the folder, click the address bar, type  cmd  and press Enter
     Mac:     right-click the folder > New Terminal at Folder
5. Run these commands one at a time:
     npm install
     npm install -g eas-cli
     eas login
     eas init
     eas build -p android --profile preview
6. When it asks:
     "Create an EAS project?" / "Link to project?" -> Yes
     (eas init writes your project ID into app.json - needed before building)
     "Generate a new Android Keystore?"      -> Yes
7. Wait for the build. When it finishes you get a link and a QR code.
   Open the link on your phone and download the APK.
8. Tap the APK to install. If Android blocks it, allow
   "Install unknown apps" for your browser or Files app when prompted.
9. First launch: allow Location and Notifications.

CHECK ON THE PHONE AFTER INSTALLING
1. "What's new" opens once. Tap Got it.
2. Home: tick a prayer with its circle. Its alert for that prayer goes away.
   Tap a prayer name: the prayer page opens with the Rak'ahs list.
3. Settings: tap your initials (top right). Sync now should say "Synced".
   On a second phone with the same Google account, Sync now there too:
   both should show the same ticks.
4. Essentials tab: Qibla, Mosques near me (needs internet), Learn.
   Learn > Kids games > Match the dua: play one round.
5. Ibadah: the search button (top right) opens Ask Deen. Try "iftar time"
   or "can't sleep".
6. Ibadah > Guides: Quran and 99 Names cards at the top.
7. Switch the language to Bangla in Settings and look around once.
8. Settings > About: tap the version 5 times to open "Preview a day" and
   try Ramadan day 1. Tap the gold bar to exit. Nothing is saved.
9. Add the widget again if it looks old, and check it ticks a prayer.

LATER
- Next update: raise "version" and "versionCode" in app.json (e.g. 1.0.2
  and 3), then run the last command from step 5 again.
  Installing the new APK over the old one keeps your data.
  Always build from the same Expo account - it holds the signing key, and
  Android only installs updates signed with the same key.
- Rename the app: change "name" in app.json.
- Try it without building: run  npx expo start  and scan the QR code
  with the Expo Go app.
- Publishing on Google Play one day: remove "android.permission.USE_EXACT_ALARM"
  from app.json first (Play only allows it for alarm-clock apps).
